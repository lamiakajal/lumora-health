# Lumora Health

Full-stack hospital website and appointment booking platform for patients in the United States and Canada.

> Work in progress. A full README with screenshots and demo GIFs will land before the first release.

## Tech stack

Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · BetterAuth · MongoDB + Mongoose · Zod · Stripe · Resend · Vitest · GitHub Actions

## Getting started

```bash
nvm use            # Node 22
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command             | What it does                  |
| ------------------- | ----------------------------- |
| `npm run dev`       | Start the dev server          |
| `npm run build`     | Production build              |
| `npm run lint`      | ESLint                        |
| `npm run typecheck` | TypeScript check (no emit)    |
| `npm run test`      | Run Vitest once               |
| `npm run format`    | Format everything w/ Prettier |
